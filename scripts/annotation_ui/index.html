Controls & saving

Paint with the selected class. Use background (0) to erase animals; ignore (255) excludes uncertain pixels. Polygon: click vertices, Enter or double-click to fill; Esc cancels. Rectangle: drag to fill.

Wheel: zoom at cursor. Space + drag: pan. Hold H: hide overlay. Alt + click: pick class. Keys 0–4 select classes; I selects ignore. Ctrl Z: undo, Ctrl Shift Z: redo.

Brush size is measured in original image pixels. Saving creates a new local mask revision. Reference seeds and original predictions stay unchanged.
